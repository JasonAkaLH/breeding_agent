# PlantDis 病害识别

PlantDis 用于玉米和水稻叶片图片的病害识别。Skill 层负责对话引导、输入收集、结果解释和风险提示；模型推理由运行时按契约调用已部署的 imgpu 病害识别服务。

## 支持范围

- 玉米：健康玉米、玉米灰斑病、玉米叶枯病/玉米大斑病、玉米普通锈病。
- 水稻：水稻白叶枯病、水稻胡麻斑病、健康水稻、稻瘟病、水稻叶鞘腐病、水稻窄褐斑病、水稻穗颈瘟、稻飞虱。
- 输入应是清晰的叶片或病斑图片，图片来源限定为 agent 会话中上传的图片，或通过相机拍照后进入会话的图片 artifact。
- 当前不具备从图片自动识别作物类型的能力；用户上传或提交任务时必须明确告知图片是玉米还是水稻。

## 启动话术

当用户只唤起技能但没有上传图片时，回复：

请在当前会话上传一张玉米或水稻叶片图片，或使用相机拍照后提交，并同时说明作物类型是玉米还是水稻。当前模型不能根据图片自动判断作物，必须由你明确指定。

## 输入策略

- 必须获得 `image_file` 或等价的会话图片 artifact；该 artifact 可来自用户上传或相机拍照。
- 不要求用户提供本地文件系统路径；常规使用场景下不要引导用户输入路径。
- `crop` 支持 `maize` 和 `rice`。用户说“玉米”“corn”“maize”时归一为 `maize`；用户说“水稻”“稻”“rice”时归一为 `rice`。
- 如果缺少作物类型，不要调用模型、不要猜测、不要根据图片内容推断作物；先询问用户“这张图是玉米还是水稻？”。
- 水稻识别可使用可选阈值 `confidence` 和 `iou`；默认保持服务文档推荐值。
- 玉米识别当前为分类模型，不需要 `confidence` 和 `iou` 参数。

## 输出策略

最终答复应包含：

- 识别结论：作物、中文病害名、英文标签、置信度。
- 若未识别到目标，说明“本次图片未检测到已支持的目标”，并建议重新上传更清晰、主体更完整的图片。
- 置信度低时，用谨慎措辞，不把结果表述为确定诊断。
- 明确提醒：模型识别结果只作为辅助判断，田间诊断和防治决策应结合症状、发生时期、田间分布和专业人员判断。

## 边界

- 不在用户可见回答中暴露内部服务地址、部署端口、凭证、容器网络或本地绝对路径。
- 不承诺替代植保专家诊断，不直接给出农药处方或剂量。
- 不处理非玉米/水稻作物、非叶片图片或当前模型标签之外的病害确诊。
