# PlantDis 使用边界

## 入口

PlantDis 只处理 agent 会话中的图片 artifact。图片 artifact 可以来自：

- 用户在会话中上传图片。
- 用户调用相机拍照后提交到会话。

常规用户流程不接收本地文件系统路径，也不要求用户输入路径。

## 必填信息

每次识别必须具备：

- `image_file`：会话图片 artifact。
- `crop`：用户明确指定的作物类型，只能是 `maize` 或 `rice`。

用户可以用中文或英文表达作物：

- 玉米、corn、maize -> `maize`
- 水稻、稻、rice -> `rice`

## 缺失输入

缺少图片时，提示用户在当前会话上传图片，或使用相机拍照后提交。

缺少作物类型时，只追问：

```text
这张图片是玉米还是水稻？
```

当前 PlantDis 不具备从图片自动识别作物类型的能力。缺少作物类型时不能猜测，不能根据图片推断，也不能先调用模型。

## 输出边界

用户可见回答应简短说明：

- 作物类型。
- 中文病害名。
- 英文标签。
- 置信度。
- 模型结果仅作辅助判断，需要结合田间症状和专业判断复核。

未检测到支持目标时，说明未检测到当前支持的病害目标，并建议重新上传或拍摄更清晰、主体更完整的叶片图片。

## 不做范围

- 不根据图片判断作物。
- 不支持玉米、水稻之外的作物。
- 不识别当前模型标签表之外的病害。
- 不做多图批量识别。
- 不生成诊断报告。
- 不输出农药剂量、施药方案或替代专家诊断。
- 不在用户可见内容中暴露内部服务地址、端口、凭证或部署细节。
