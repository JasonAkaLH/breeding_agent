# PlantDis API 使用说明

PlantDis 当前支持玉米和水稻叶片病害识别。Skill 的常规入口是在 agent 会话中上传图片，或调用相机拍照后把照片作为会话图片 artifact 提交；模型推理由运行时调用已部署的 imgpu 服务完成。

重要边界：当前 PlantDis 不具备从图片自动识别作物类型的能力。用户必须在上传或提交任务时明确说明图片是玉米还是水稻；缺少作物类型时应先追问，不能调用模型或猜测。

图片 artifact 进入 Skill 后，由运行时交给 imgpu 识别接口。常规用户路径不要求也不鼓励输入本地文件系统路径。

## 调用语义

- 水稻模型是检测任务，业务语义为“检测图片中的水稻病害目标”。可传 `confidence` 和 `iou`。
- 玉米模型是分类任务，业务语义为“判断图片最可能的玉米病害类别”。
- 当前识别接口统一返回 `model_name` 和 `result`。
- `result` 为对象时，包含 `chinese_name`、`english_label` 和 `confidence`。
- `result` 为 `null` 时，表示请求成功但未检测到当前支持的目标，不应当当作服务错误。

## 用户解释边界

- 高置信度结果可以表述为“模型识别为……”，不要表述为“确诊”。
- 低置信度结果应提示“仅供参考，建议补充更清晰图片或结合田间症状复核”。
- 健康标签表示模型在当前支持类别内更倾向于健康，不代表植株没有其他未覆盖病虫害或生理胁迫。
- 不输出农药剂量、施药处方或不可逆生产建议。

## 错误处理

- 图片无法解析：提示用户上传清晰、常见格式的图片。
- 图片过大：提示用户压缩图片后重试。
- 请求超时或服务内部错误：提示稍后重试，并保留可诊断的运行日志。
- 缺少作物类型：询问用户图片是玉米还是水稻。
