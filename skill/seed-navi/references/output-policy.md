# Seed Navi 输出策略

用户可见产物由 Skill 层组织和返回，重点包括：

- 候选品种列表。
- 适应性 HTML 地图/报告。
- 目标品种、对照品种和区域摘要。
- 后续追问可复用的会话事实。

计算服务返回的 JSON 和 GeoJSON 是计算事实；常规答复不展示它们的内部路径。

## 最终答复

用户可见最终答复应包含：

- 目标品种。
- 对照品种。
- 当前分析区域，并明确显示为东北中晚熟区。
- 可用时展示匹配点数、模型点数、网格数量和散点数量。
- HTML 报告链接。
- 简洁证据边界说明。

除非用户要求调试细节，不要输出原始 JSON 路径、临时目录或服务运行细节。
