# Seed Navi 流程

## 渐进流程

1. 接收试验文件。
2. 缺少目标品种时，先在 Skill 层识别候选品种。
3. 展示候选品种、记录数和年份。
4. 请用户提供目标品种全名或品种代码。避免编号候选列表，展示真实品种名/代码。
5. 默认使用东北中晚熟区 (`zhongwanshu`)，不要询问生态区。
6. 除非用户提供其他对照，默认使用 `CK`。
7. 运行适应性分析。
8. 获取地图渲染所需产物。
9. 渲染 HTML 报告并记录会话状态。
10. 返回中文解读。

## 分析阶段

Seed Navi 包含候选品种识别、目标品种适应性分析和地图报告渲染三个主要阶段：

- 品种识别阶段用于从试验表中找出候选品种。
- 适应性分析阶段使用目标品种、对照品种和默认区域生成模型结果。
- 地图渲染阶段把模型结果整理为用户可读 HTML。

默认参数：

- `control_variety`: `CK`
- `top_n`: `20`
- `quantile`: `0.6`
- `distance_limit_km`: `50.0`
- `year_window`: `5`

不要向用户展示内部传输方式、服务接口、容器路径或调试命令。

## 直接运行

当文件、目标品种和对照品种都已明确时，直接用默认东北中晚熟区运行，不再插入中间确认。
常规流程不要求用户理解上传引用、共享目录或运行目录。
