# Rice Genie Report Style

## Default Structure

Use the key-trait report as the default first response.

For multiple materials:

1. Multi-sample overview table with sample id, favorable-variant count,
   detection rate, core advantages, and recommended use.
2. Deep interpretation for at most the first three samples unless the user
   requests specific sample IDs.
3. Cross-sample comparison across yield, resistance, quality, nitrogen-use,
   plant type, abiotic stress, and seed-shape signals when supported.
4. Breeding suggestions and possible trait complementation.
5. Concise evidence boundary note.

For a single material:

1. Overall assessment.
2. Yield potential analysis.
3. Resistance evaluation.
4. Environmental adaptability.
5. Quality and plant type.
6. Nitrogen-use efficiency only when strongly supported.

## Trait Priority

Prioritize:

1. Yield.
2. Quality.
3. Plant type.
4. Biotic stress resistance.
5. Abiotic stress and other agronomic traits when useful.

## Language

Use evidence-bounded Chinese wording such as:

- 预期
- 提示
- 具有潜力
- 可作为参考

Do not promise actual field performance, commercial value, or deterministic
phenotypes from marker evidence alone.

## Detail Tables

Do not include long favorable-site tables by default. When the user asks for
QTN/gene details, show compact columns:

- QTN id.
- Gene name.
- Trait type.
- Phenotype.
- Detected genotype type.
- Favorable label.
- Review note.

When a table is long, group by sample and trait and show the most relevant rows
first.
