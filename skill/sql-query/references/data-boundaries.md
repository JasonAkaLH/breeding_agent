# 数据边界

## 只读边界

仅支持受控只读查询；不执行写入、修改、删除、DDL、权限变更、多语句 SQL 或高风险管理操作。

禁止事项：

- 不暴露数据库连接信息、账号、密码、LLM key、完整 prompt、handler、service、内部配置或本机路径。
- 不让普通脚本直接绑定数据库、内部 LLM、secret 或完整环境变量。
- 不把平台 SQL guard、schema context 或 service allowlist 作为面向用户的实现细节展示。

## 数据解释边界

- 缺少关键查询实体时返回可控澄清，不编造 SQL 或业务数据。
- 未命中结果时说明可能原因和可补充条件。
- 结果过多时说明截断或筛选策略，并建议用户缩小范围。
