# 田间数据分析职责边界

## 职责划分

计算后端负责统计模型拟合和报告事实；Skill 层负责输入适配、文件转换、HTML 渲染、中文
解释、会话状态和用户可见输出。

不要从本 Skill 直接运行本地 R 分析脚本。统计计算应由运行时配置的后端完成。

## 用户可见说明

用户不需要了解服务地址、环境变量或部署拓扑。出现错误时，用普通语言说明：

- 输入数据是否缺少固定列或有效性状列。
- 设计类型是否无法识别为 `rcbd` 或 `diagonal`。
- 某个统计章节是否失败、跳过或不适用。
- 如果是计算服务暂不可用，说明需要稍后重试或让维护者检查运行环境。

## 调试边界

面向用户的错误不要暴露容器路径、服务 payload、凭据、本地绝对路径或调试文件。除非用户
明确要求排查运行环境，否则不要讨论端口、URL、进程或部署细节。

后续追问应优先使用已返回的报告事实和活动会话，而不是让用户提供内部 JSON 文件路径。
