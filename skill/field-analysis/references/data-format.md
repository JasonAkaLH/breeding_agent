# 田间表型数据格式

## 支持的文件

支持 CSV 或 Excel（`.csv`、`.xlsx`）。数据应为宽表：每一行代表一个小区、条目或田间观测，表中包含必要信息列和一个或多个性状列。

表头不强制使用固定英文名，也不要求固定列顺序。skill 会把常见中文或英文语义表头归一到内部字段，其余非元数据列会作为性状列保留原始表头。

## 必要信息列

常规分析需要包含这些信息：

```text
试点、流水号、材料名称/代号、是否对照、一个或多个性状列
```

RCBD 还需要 `区组/重复`，用于识别区组或重复。

Diagonal 设计中的 `区组/重复` 可缺省；未提供时默认按 `1` 个重复处理。

`排号` 和 `列号` 对 RCBD 与 Diagonal 都不是常规分析的阻断必需列。它们用于空间校正或空间诊断；如果缺失，skill 仍可进行常规表型分析，但应提醒用户：如需田间空间校正或空间诊断，请补充排号和列号。

当所有元数据字段都可用时，内部字段顺序为：

```text
loc_id,rep_num,ranges,pass,entry_id,ped_id,check_type
```

## 列名映射

| 内部字段 | 中文标准名 | 可识别表头示例 |
| --- | --- | --- |
| `loc_id` | 试点 | 地点、环境、试验地点、地点编号、试点编号、site、location、env |
| `rep_num` | 区组/重复 | 重复、区组、重复编号、区组编号、rep、block、r |
| `ranges` | 排号 | 行号、垄号、田间排号、row、range |
| `pass` | 列号 | 田间列号、col、column |
| `entry_id` | 流水号 | 小区号、小区编号、条目编号、plot、plots、entry |
| `ped_id` | 材料名称/代号 | 材料、品种、品种名称、材料编号、材料代号、组合名称、material、genotype、variety |
| `check_type` | 是否对照 | 对照、对照标记、对照类型、CK、check、control、is_check |

## 对照取值

`check_type` 会在分析前归一化。

以下值按测试材料处理：

```text
空值, 0, 0.0, test, tester, non-check, material, entry, no, false, 否, 不是, 测试, 测试材料, 试验材料, 非对照, 非对照材料, 材料
```

以下值按对照材料处理：

```text
1, 1.0, ck, check, control, yes, true, 是, 对照, 对照材料
```

其他非空值会按对照材料处理，避免用户使用具体对照名称时被误删。

## 性状列规则

除元数据列之外的列会作为性状列保留原始表头，例如 `产量`、`株高`、`水分`、`T002`、`T0166`。

数值型性状会进入完整分析流程。分类或非数值性状只做描述统计，不进入 ANOVA、LSD、BLUP 或稳定性模型分析。

空值或非数值单元格会在数值模型分析中忽略。

在独立性状元数据文件引入前，`T0166` 按低值更优处理，其他性状按高值更优处理。
