# 材料清单格式

## 支持文件

支持 CSV 或 Excel（`.csv`、`.xls`、`.xlsx`）。每一行代表一个参试材料或对照材料。

材料清单不强制固定列名，也不要求固定列顺序。用户只需提供所选设计需要的信息：
材料名称/代号、是否对照，以及在存在分组时提供组别/分组。列名可以使用中文或英文语义名称。

规范化后的内部字段如下。这里的字段名是运行时内部字段，用户表格可以使用下方列出的中文或英文语义表头。

| 内部字段 | 含义 | 规则 |
| --- | --- | --- |
| `ped_id` | 材料名称/代号 | 必需，非空文本或数字；作为材料标识处理，不作为连续数值性状。 |
| `hyb_check` | 是否对照/材料类型 | RCBD 可缺省；当设计需要显式对照时应提供。不同设计的取值含义见下文。 |
| `set` | 组别/分组 | 所有材料属于同一组时可缺省；同一组内材料使用相同 `set`。 |

## 可识别表头

| 信息 | 可识别表头示例 |
| --- | --- |
| 材料名称/代号 | `ped_id`、`material`、`material_name`、`variety`、`cultivar`、`genotype`、`accession`、`name`、`名称`、`材料`、`材料名称`、`材料编号`、`品种`、`品种名称`、`品种编号` |
| 是否对照 | `hyb_check`、`check`、`is_check`、`ck`、`type`、`material_type`、`hyb_type`、`design_check`、`对照`、`是否对照`、`对照标记`、`是否CK`、`CK标记`、`材料类型`、`类型` |
| 组别/分组 | `set`、`group`、`set_id`、`trial_set`、`组别`、`分组`、`材料组`、`试验组`、`组`、`群组` |

## `hyb_check` 取值规则

- RCBD：`0` 表示普通测试材料，非 `0` 表示对照。
- Diagonal：`2` 表示对角线设计对照材料，`0` 或 `1` 表示非对角线对照的普通材料。
- Interval：`0` 表示普通测试材料，非 `0` 表示 CK/对照。

当用户提供 `是`、`否`、`CK`、`check`、`true`、`false`、`1`、`0` 等语义取值时，skill 会按设计类型归一化：
Diagonal 中语义对照会转换为 `hyb_check=2`；RCBD 和 Interval 中语义对照会转换为 `hyb_check=1`。

## RCBD 仅材料名称输入

RCBD 可以只提供材料名称/代号清单，不需要完整三列表格。支持：

- 在对话中粘贴一串材料名称，用换行、英文逗号、中文逗号、顿号、分号或制表符分隔。
- 上传只有一个材料列的 CSV/Excel 表。可识别表头包括 `ped_id`、`material`、`material_name`、`variety`、`cultivar`、`genotype`、`accession`、`name`、`材料`、`材料名称`、`材料编号`、`品种`、`品种名称`、`品种编号`。

RCBD 收到仅材料名称输入时，会自动生成 `ped_id=<用户提供的名称>`、`hyb_check=0`、`set=1`。
用户仍需提供或确认 RCBD 的区组数/重复数；未指定时使用默认重复数。

用户也可以在对话中单独说明对照材料，例如 `checks are CK1, CK2` 或 `对照品种是先玉335、迪卡653`。
RCBD 会把这些名称加入材料表并标记为 `hyb_check=1`；如果名称已经在普通材料清单中，对照标记优先。

## 示例

| ped_id | hyb_check | set |
| --- | --- | --- |
| A001 | 0 | A |
| A002 | 0 | A |
| CK_A | 1 | A |
| B001 | 0 | B |
| B002 | 0 | B |
| CK_B | 1 | B |

Diagonal 设计中，对角线对照行应使用 `hyb_check=2`。

Interval 设计中，同一 `set` 内每个 CK 的 `ped_id` 应唯一；不同 `set` 可以复用同一个 CK 名称。
