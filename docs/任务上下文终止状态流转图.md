# Task Context Termination（主动停止）状态流转图

> 适用范围：当前仓库 Phase 3 已实现的生命周期语义  
> 相关实现：`src/lifecycle/cancellation_service.py`、`src/lifecycle/task_state_machine.py`

## 1. 总体流转图

```mermaid
flowchart TD
    A[收到主动停止请求 cancel_task_context(task_id)] --> B[Task: running -> cancelling]
    B --> C[扫描该 task 下所有 TaskNode]
    B --> D[扫描该 task 下所有 Interrupt]
    B --> E[扫描该 task 下所有 Checkpoint]
    B --> F[扫描该 task 下所有 MailboxMessage / MailboxDelivery]

    C --> C1[pending / ready -> blocked_by_cancellation]
    C --> C2[running -> cancelled]
    C --> C3[waiting_for_dependency -> cancelled]
    C --> C4[waiting_for_input -> cancelled]
    C --> C5[ready_to_resume / resuming -> cancelled]
    C --> C6[completed -> 保持 completed]

    D --> D1[open / answered -> cancelled]
    E --> E1[checkpoint.invalidated_at = now]
    F --> F1[未完成 delivery -> cancelled]

    C1 --> G[Task: cancelling -> cancelled]
    C2 --> G
    C3 --> G
    C4 --> G
    C5 --> G
    C6 --> G
    D1 --> G
    E1 --> G
    F1 --> G

    G --> H[late result rejected]
    H --> I[can_accept_late_result(task_id) = false]
```

## 2. 对象级收敛规则

| 对象 | 主动停止后的处理 |
|---|---|
| `Task` | `running -> cancelling -> cancelled` |
| `TaskNode(pending/ready)` | `-> blocked_by_cancellation` |
| `TaskNode(running)` | `-> cancelled` |
| `TaskNode(waiting_for_dependency / waiting_for_input / ready_to_resume / resuming)` | `-> cancelled` |
| `TaskNode(completed)` | 保持 `completed` |
| `Interrupt` | `-> cancelled` |
| `Checkpoint` | 写入 `invalidated_at`，不允许后续 resume |
| `MailboxDelivery` | 未完成的 delivery 统一 `-> cancelled` |
| `Late Result` | 不再回写主任务，逻辑拒收 |
