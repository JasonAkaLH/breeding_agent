# Phase 3 — 业务对话台 UI 主路径

## 目标

完成业务用户可理解的单页对话体验：输入、提交、实时回答、状态提示、取消和错误提示。

## 页面结构

1. 顶部栏：产品名、环境标识、能力状态。
2. 对话区：用户气泡、助手 streaming 气泡、SQLQuery 结果卡片、任务状态提示。
3. 输入区：多行输入、当前模式“自动规划”、提交按钮、取消按钮。
4. 轻量提示：根据“查询、品种、基因型、审定”等关键词提示主代理会自动判断是否调用 SQLQuery，不再要求用户切换 capability。

## 交互规则

- 提交时立即插入用户消息和 assistant 占位消息。
- 当前任务运行中禁用再次提交；如后端返回 409，展示业务化提示。
- `main_agent.output_delta` 到达时滚动到底部并追加文本。
- 取消按钮只在任务运行中展示，点击后立即进入取消中状态。
- 错误提示不得展示堆栈、provider secret 或内部异常全文。

## 验收标准

- 组件测试覆盖自动规划提交、数据库类问题无需手动模式选择、409 提示。
- 人工验证可看到 streaming 文本追加和任务状态变化。
