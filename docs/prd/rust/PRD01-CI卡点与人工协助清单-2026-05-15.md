## 已经修掉的两个 CI 问题

### 1. `rust_branch` 推送不触发 CI

之前 workflow 只监听 `main` push，所以我每次推到 `rust_branch` 后 `gh run list --branch rust_branch` 都是空。

已修复：`.github/workflows/rust-quality.yml` 的 push 分支已包含 `rust_branch`。

### 2. fuzz job 两次失败

第一次失败：

- run：`25912752831`
- 失败点：`cargo install cargo-fuzz --locked`
- 原因：Ubuntu 22.04 + nightly 2026-05-15 下，locked 依赖里的 `rustix 0.36.5` 使用了现在会被拒绝的 `rustc_*` 保留 attribute。

已修复：固定顶层 `cargo-fuzz 0.13.1`，但不再使用 `--locked`，让 Cargo 解析兼容依赖。

第二次失败：

- run：`25913275197`
- 失败点：`cargo fuzz run ...`
- 原因：`native/rust-toolchain.toml` 把 workspace 固定到 stable `1.95.0`；`cargo fuzz` 需要 `-Zsanitizer`，只能用 nightly。

已修复：workflow 和本地 gate runner 都改为显式 `cargo +nightly fuzz run ...`。

最新 run `25913656324` 里，fuzz job 已通过，说明上述两个 fuzz 问题已解决。
