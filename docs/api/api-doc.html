快速接入

最短接入链路：验证码 → 登录 → 提交消息 → 监听任务事件。

1

获取验证码

调用 POST /api/v1/auth/captcha，把 SVG 展示给用户。

2

建立登录会话

同站同域浏览器使用服务端写入的 __Host-maf_session；跨站或非浏览器客户端先创建 scoped Bearer token。

3

提交消息

向会话提交内容，拿到 task_id。

4

监听 SSE

订阅任务事件，实时渲染节点输出、产物和中断。

认证规则

登录和注册依赖验证码；登录成功后服务端只写入 opaque __Host-maf_session，不在 Cookie 暴露用户名。该 Cookie 使用 HttpOnly、Secure、SameSite=Lax、Path=/ 且不设置 Domain；旧 maf_session 仅作为只读迁移 fallback。跨站/第三方浏览器前端和非浏览器客户端默认使用 Authorization: Bearer <opaque-token>，不要把 token 放入 URL query。

会话规则

conversation_id 由调用方生成或复用；官方非 GET 路由不在 URL 中携带业务 ID，统一放入 JSON body 或 multipart form；同一会话同一时间只允许一个未完成任务。

任务规则

提交消息返回 task_id；任务输出以 SSE 为主，任务摘要、图、等待输入和产物接口用于状态恢复与补充展示。

Cookie 结构

同站同域浏览器登录态只使用服务端写入的 opaque session Cookie。Cookie 中不放用户名、账号、角色、scope 或其他用户资料。

Cookie 名称

正式 Cookie 名称为 __Host-maf_session。__Host- 前缀要求更严格的浏览器约束：必须是 secure cookie、路径为 /，且不能设置 Domain。

Cookie 值

值是服务端生成的 opaque session_id 字符串，只能作为查表凭证使用；客户端不能从值里解析用户身份。用户名只在服务端 session 存储中关联，不写入 Cookie。

安全属性

服务端写入 HttpOnly、Secure、SameSite=Lax、Path=/，且不设置 Domain；当前最大存活时间为 28800 秒。

迁移兼容

旧 maf_session 只作为只读迁移 fallback 解析；新登录/注册只写 __Host-maf_session。登出会同时清理新版和旧版 Cookie。

跨站 / 非浏览器

跨站前端、第三方浏览器场景和非浏览器客户端默认不要依赖 Cookie；应使用 Authorization: Bearer <opaque-token>，并通过 CORS allowlist 放行明确 origin。

示例
Set-Cookie 示例
Set-Cookie: __Host-maf_session=<opaque-session-id>; Max-Age=28800; Path=/; SameSite=Lax; Secure; HttpOnly

推荐调用流程

业务对话台通常按下面顺序串联接口；SSE 是任务输出的主通道。

启动

GET /auth/me 可用 Cookie 或 Bearer 校验登录态；GET /capabilities 初始化公开能力列表；GET /conversations 以认证身份恢复历史会话。

对话

可先上传附件，再调用 POST /conversations/chat-messages；conversation_id 放在 body。响应中的 task_id 是后续查询核心。

收尾

SSE 完成后读取 messages 与 artifacts；文件 artifact 用 download_url 或下载接口获取。

POST
需同站 Cookie · 创建 Bearer token

创建 API token

为跨站/第三方浏览器前端或非浏览器客户端创建 opaque Bearer token。服务端只保存 hash；明文 access_token 只在创建响应返回一次。

参数 / 请求 / 响应 / 下一步
请求说明

Content-Type: application/json；必须携带同站 Cookie session；Bearer token 不能创建新 token。

响应

201 CreateApiTokenResponse：token 元数据 + 一次性明文 access_token。

错误

400：client_name、scope 或 TTL 非法；401：无有效 Cookie session。

下一步

立即保存 access_token；后续业务 API 使用 Authorization: Bearer。

参数明细

参数位置类型必填简介枚举 / 默认
__Host-maf_sessionCookiestring是同站登录 session id；仅用于一方浏览器 token 管理，不暴露用户名。HttpOnly / Secure / SameSite=Lax
client_nameBodystring是客户端名称；归一化空白后长度必须为 1-80 个字符。—
scopesBodyarray<string>是授权范围；至少 1 个，重复值会去重。conversation:read / conversation:write / task:control / upload:write / capability:read
ttl_secondsBodyinteger|null否token 有效期秒数；为空时使用默认 28800 秒，最大 604800 秒。1..604800 / 默认 28800

返回参数明细

字段类型必返简介枚举 / 备注
token_idstring是服务端生成的 token 元数据 ID；后续撤销时使用。—
client_namestring是创建请求中的客户端名称。—
scopesarray<string>是该 token 被授予的业务权限列表。conversation:read / conversation:write / task:control / upload:write / capability:read
expires_atstring(date-time)是token 失效时间，ISO 8601 格式。—
revoked_atstring(date-time)|null否撤销时间；新创建 token 通常为 null。—
created_atstring(date-time)|null否token 创建时间。—
last_used_atstring(date-time)|null否最近一次成功使用 Bearer token 的时间。—
access_tokenstring是仅创建响应返回一次的 opaque Bearer token 明文；服务端只保存 hash。客户端必须自行安全保存；后续列表不会再返回
正式 curl 调用模板
curl -X POST "${BASE_URL}/api/v1/auth/api-tokens" \
  --cookie "__Host-maf_session=${SESSION_COOKIE}" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{ "client_name": "manual-smoke", "scopes": ["conversation:read", "conversation:write"], "ttl_seconds": 3600 }'
response 样式
{
  "token_id": "{token_id}",
  "client_name": "manual-smoke",
  "scopes": ["conversation:read", "conversation:write"],
  "expires_at": "{iso_datetime}",
  "access_token": "maf_tok_..."
}

SSE 流式事件

GET /api/v1/tasks/{task_id}/events 返回 text/event-stream。每条 data 是 JSON 字符串，解码后为 TaskEventEnvelope。

连接要求同站浏览器客户端可携带有效 __Host-maf_session Cookie；跨站 Bearer 客户端必须使用可设置 Authorization header 的 fetch stream，并保持长连接读取 text/event-stream。
事件结构每条事件包含 SSE id、event 与 JSON 字符串 data；data 解码后为 TaskEventEnvelope。
断线处理客户端应按浏览器或 HTTP 客户端策略重连；需要校准状态时回查 GET /api/v1/tasks/{task_id}。
event_idSSE id 同值，可作为前端去重 / 日志追踪键。
event_typeSSE event 同值；前端按类型分发渲染。
payload事件载荷，可能包含文本增量、节点状态、产物或 interrupt。

错误与状态码

API 使用 HTTP status 表达通用错误；FastAPI 参数校验错误通常为 422。

400 请求错误（Bad Request）

请求语义不合法，例如 scope 值非法、文件内容不符合要求。

401 未认证（Unauthorized）

未登录、会话过期、Bearer token 无效，或验证码/账号密码校验失败。

403 权限不足（Forbidden）

Bearer token 有效但缺少业务接口要求的 scope，例如写接口缺 conversation:write 或 task:control。

404 未找到（Not Found）

会话、任务、上传或产物不存在，或不属于当前用户。

409 冲突（Conflict）

会话已有运行中任务，或 interrupt 已关闭等并发状态冲突。

410 已失效（Gone）

文件产物 retention 失效，不能再下载。

422 校验错误（Validation Error）

路径、查询或请求体字段类型不满足 OpenAPI schema。
