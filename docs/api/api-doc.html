小奥 Agent API 文档

当前认证模型为 Authorization-only username token：登录只提交 username，服务端返回当前有效 access_token；后续所有受保护 REST、multipart upload 与 SSE fetch-stream 请求都必须携带 Authorization: Bearer <access_token>。除登录外，请求体、query param 与业务 metadata 不承载用户身份。

认证

方法路径说明
POST/api/v1/auth/login请求体只允许 username。若用户名尚无映射则创建；无论是否已有映射，都会签发一个新的当前 token，旧 token 立即失效。
GET/api/v1/auth/me通过 Authorization token 定位当前用户。
POST/api/v1/auth/refresh-token通过当前 token 定位用户，并原子替换为新的当前 token；旧 token 立即失效。
POST/api/v1/auth/logout通过当前 token 定位用户并清空 token，保留用户名映射行。
curl -X POST "${BASE_URL}/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"alice"}'
{
  "user": { "username": "alice" },
  "access_token": "maf_tok_xxx"
}

会话与消息

方法路径说明
POST/api/v1/conversations/chat-messages提交用户消息并创建任务。owner 只能由 Authorization token 解析出的 username 决定；请求体不允许身份字段。
GET/api/v1/conversations列出当前用户自己的会话。
PATCH/api/v1/conversations按 conversation_id 重命名当前用户会话。
DELETE/api/v1/conversations删除当前用户会话，并清理其消息、任务、事件与关联文件记录。
GET/api/v1/conversations/{conversation_id}/messages读取当前用户指定会话的历史消息。
GET/api/v1/conversations/{conversation_id}/tasks?scope=unfinished|all列出当前用户指定会话的任务；无权访问时返回空列表或 404 语义。
curl -X POST "${BASE_URL}/api/v1/conversations/chat-messages" \
  -H "Authorization: Bearer ${ACCESS_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "conversation_id":"conv-1",
    "content":"你好",
    "routing_mode":"auto",
    "capability_id":null,
    "client_message_id":null,
    "metadata":{}
  }'

会话上传

方法路径说明
POST/api/v1/conversations/uploadsmultipart upload；file 放文件，conversation_id 放 form field，Authorization 放 header。
GET/api/v1/conversations/{conversation_id}/uploads列出当前用户会话的未过期上传。
DELETE/api/v1/conversations/uploads按 conversation_id 与 upload_id 删除上传记录。

任务、事件、产物与中断

方法路径说明
GET/api/v1/tasks/{task_id}读取当前用户任务摘要。
GET/api/v1/tasks/{task_id}/eventsSSE fetch-stream。token 不放 URL；服务端在事件发送前持续校验当前 token，刷新或登出后旧流不能继续收到事件。
POST/api/v1/tasks/cancel请求取消当前用户任务，body 为 {"task_id":"..."}。
GET/api/v1/tasks/{task_id}/interrupts列出当前用户任务待回答的 interrupt。
POST/api/v1/tasks/interrupts/answer提交 interrupt answer。answer_payload 不承载用户身份。
GET/api/v1/tasks/{task_id}/graph读取当前用户任务 DAG 节点与边。
GET/api/v1/tasks/{task_id}/artifacts列出当前用户任务产物。
GET/api/v1/artifacts/{artifact_id}/download下载当前用户任务所属文件产物；无权访问返回 404。

能力目录

方法路径说明
GET/api/v1/capabilities列出公开可用能力 / Skill；该目录为 public endpoint，无需 Authorization。

错误语义

HTTP 状态语义
400业务参数不合法或当前状态不允许。
401缺少 Authorization、token 不存在、已被刷新替换或已登出。
404资源不存在，或资源不属于当前用户。
409会话已有未完成任务。
422请求 schema 不合法，或 body / metadata / answer_payload 携带保留身份字段。
